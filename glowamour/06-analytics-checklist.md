## PART A — How to Use Instagram Insights (Simple English)

> Insights = Instagram’s free report card for Business accounts. It tells you: Who saw you? Did they care? Did they visit/DM/buy?

**How to open:**
- Profile → `☰ Menu → Insights` (or `Professional Dashboard → Insights`).
- Per-post: Open any Reel/Post → `View Insights`.
- Per-Story: Open Story → `Seen by → Insights icon`.

**Check weekly (Sunday 15 min). Check monthly (1 hour deep dive). Don’t check hourly — noise, not signal.**

### Metrics that matter for GLOWAMOUR (in priority order)

1. **Accounts Reached + Non-follower %** — Are NEW right people finding you? Goal: non-follower % rising on Reels (50-80% early is healthy for reach Reels; lower for follower-nurture posts).
2. **Reel Views + Watch Time / Avg Watch + Completion** — Did they stay? If avg watch <3 sec, hook failed. If drop at 50%, middle dragged. Rewatch = strong.
3. **Shares + Saves** — Strongest “useful” signals for skincare. Saves = routine/FAQ value. Shares = “send to sister/friend”. Track per post, not just likes.
4. **Profile Visits + Follows from Content** — Did reach CONVERT? High views + low visits = weak hook-to-profile link (fix bio/pins/CTA). High visits + low follows = profile unclear (fix Name/Bio/Pins/Highlights).
5. **Link Taps / WhatsApp Button Taps** — Did they try to BUY? `Insights → Profile → Link taps / Contact button taps`. Low taps = CTA unclear or trust low.
6. **DMs + Comments with “GLOW”** — Your money metric. Count manually weekly (Instagram doesn’t auto-report keyword DMs). `GLOW DMs per 1000 views` = conversion rate.
7. **Follower Growth (net, + demographics)** — Are followers from India/Gujarat, 18-44, interested in beauty? `Insights → Audience → Top cities/countries/age`. 500 right followers > 5000 random.
8. **Sales (outside Instagram)** — WhatsApp orders, COD confirmations, repeat questions. Log in a sheet: Date | Post that drove DM | Order? | City. This ties content → cash.

**What to ignore early:** Total follower count alone, likes alone, single-post virality, “best time” myths. One viral-but-wrong audience Reel (e.g., comedy trend) can hurt conversion — niche relevance > raw views.

## PART B — Diagnose + Fix (No Guesswork)

| Symptom | Likely cause | Fix (test 3 posts, then decide) |
|---------|--------------|---------------------------------|
| Low views (<200 after 48h, new account) | Weak hook, unclear topic, inconsistent niche, no keywords | New hook in 0-1 sec + keyword spoken/shown + cover text 3-5 words + Trial Reel test + keep niche (night cream/Indian skin) for 15 posts straight |
| High views, low saves/shares | Entertaining but not useful | Add saveable steps (“3 steps… Save before tonight”) + share line (“Send to someone who skips night cream”) |
| High reach, low profile visits | No curiosity to know brand | End card: “Follow @glowamour.in for simple routines” + Pin 1 strong + Name/Bio keyword clear + CTA in caption line 1 |
| High visits, low follows | Profile unclear / no trust | Fix per File 01+03: Name, Bio A, 3 pins, 9 Highlights, grid rhythm, founder face, ingredients/price visible |
| Follows but no DMs/links | CTA weak / trust gap / price hidden | Every sales post ends “DM GLOW for price+COD” + Pinned comment same + Stories link sticker daily + publish price/COD/shipping |
| DMs but no orders | Price/shipping/COD unclear, slow replies, no COD | Reply <4 hrs (10-8), templated price+COD+address format message, offer COD, share tracking, Gujarati/Hindi support |
| Good Reels, dead Stories | Stories too salesy / no stickers | 3-5 Stories/day: poll → behind-scenes → Q&A/link. Face + captions. Save to Highlights |
| Random followers (abroad/spam) | Generic hashtags/trends, bought engagement | Cut generic tags/trends, use File 02 sets, remove obvious bots (followers → Remove), never buy followers |

**Testing rules:**
- Change ONE thing at a time (hook OR cover OR CTA, not all).
- Test minimum 3 posts per change. One post = anecdote, three = pattern.
- Keep winners log: Hook | Topic | Length | Cover | Views | Saves | Visits | GLOW DMs. Re-shoot winners with new first 2 sec monthly.
- Use Trial Reels for risky tests (new topic, Gujarati-only) so followers don’t get spammed.
