## 1. Username — What to choose, why, how

**What Instagram says (Confirmed):**
- Username is unique, max 30 characters, only letters, numbers, periods (.) and underscores (_).
- It’s part of your URL: `instagram.com/glowamour.in`
- You can change it anytime in `Edit Profile > Username`. Old handle becomes free for others.

**Expert recommendation for GLOWAMOUR — try in this order:**
1. `@glowamour` — shortest, strongest brand. Likely taken, but try first.
2. `@glowamour.in` — **RECOMMENDED DEFAULT.** Signals India, looks professional, easy to say in Reels: “Follow Glowamour dot in”.
3. `@glowamour.skincare` — good for SEO clarity if .in is taken.
4. `@myglowamour` — brandable alternative.
5. `@glowamourindia` — last resort (longer but clear).

Avoid: `@glowamour_123`, `@glowamour_ahmedabad_official__`, extra dots/underscores, “official” unless you have fakes to fight.

**How to verify availability (2 min):**
1. Instagram App → 🔍 Search → type `@glowamour.in` — if no account appears, it *may* be free.
2. Go to your profile → `Edit Profile > Username` → type it → **green tick = available, red = taken.**
3. If creating new: on signup screen, Instagram tells you instantly.
4. Also check: Facebook Page name, YouTube handle, and domain `glowamour.in` for future website consistency (use a registrar search, don’t buy yet unless you want to).

**Why it matters:** Short + memorable + consistent everywhere = people can find you from packaging, WhatsApp, word-of-mouth. SEO weight is smaller than Display Name, but clarity matters for trust.

## 2. Display Name / Name Field — Your #1 SEO lever

**Confirmed:** The Name field (top bold line, up to 64 characters) IS searched by Instagram. Keywords here help you appear for “night cream”, “skincare india”, etc.

**Recommended (copy-paste):**
```
GLOWAMOUR | Night Cream for Glowing Skin
```

**Why this wins:**
- Brand first (recognition) + what you sell + desired result.
- Matches what buyers type: “night cream”, “glowing skin”, “night cream for glowing skin”.
- 45/64 chars — leaves room to add “India” later.

**Alternatives by situation:**
- If kesar is hero + confirmed: `GLOWAMOUR | Kesar Night Cream India` (differentiates from 1000s of night creams)
- If you want local trust: `GLOWAMOUR Skincare | Ahmedabad • India`
- If soap launches soon: `GLOWAMOUR | Night Cream & Kesar Soap`
- Gujarati-inclusive (keep English for search, add city): `GLOWAMOUR | Night Cream India – Ahmedabad`

**What NOT to do:**
- Don’t stuff: `GLOWAMOUR Night Cream Glowing Skin Beauty Ahmedabad Gujarat Kesar Soap Offer COD` = spammy, hurts trust, no proven ranking boost.
- Don’t use only `GLOWAMOUR` — you waste searchable space.
- Don’t change it weekly. Instagram needs stable signals. Change max 1x/month.

**How to set:** Profile → `Edit Profile > Name` → paste → Done.

## 3. Bio — 150 characters that convert visitor → follower → buyer

**Confirmed:** Bio is searchable (keywords), 150 chars max, line breaks allowed, 1-2 emojis help scanning (not ranking). You can add up to 5 external links + social links.

**Simple English:** Bio = your shop board. In 3 seconds visitor must know: What? For whom? Why trust? How to buy?

### Recommended Bio A — Clean + Sales-focused (USE THIS FIRST)
```
✨ Night Cream for Daily Glow
🇮🇳 Made for Indian Skin | Ahmedabad
💬 Order on WhatsApp / DM “GLOW”
👇 Tap to Shop ↓
```
Count: ~118 chars. Leaves room.

### Bio B — SEO-heavy (if you want more keyword hits)
```
GLOWAMOUR Skincare India
Night Cream for Dull Skin & Dark Spots
COD Available | DM to Order
👇 WhatsApp Us:
```
Use ONLY if “dark spots” is a real, supportable use-case per your ingredients/packaging. Don’t promise removal/lightening unless you have evidence. Safer: “for dull-looking skin”.

### Bio C — Gujarati-friendly trust
```
✨ GLOWAMOUR Night Cream
Daily Glow • Made in India 🇮🇳
Ahmedabad | Gujarati Support Available
DM “GLOW” to Order 👇
```

### Bio D — When Kesar Soap launches (future)
```
✨ Night Cream + Kesar Goti Soap
Simple Night Routine for Glow
🇮🇳 Ahmedabad | COD | DM “GLOW”
👇 Shop Below:
```

**Bio rules:**
- Line 1 = WHAT (product + benefit)
- Line 2 = WHO/WHERE (Indian skin, Ahmedabad = trust + local SEO)
- Line 3 = HOW TO BUY (WhatsApp/DM + keyword “GLOW” for auto-reply filtering)
- Line 4 = Pointer to links (👇 increases taps — expert recommendation, not Instagram-confirmed ranking factor)

**How to set:** `Edit Profile > Bio` → paste with line breaks → Save.

## 4. Logo / Profile Photo — Requirements

**Confirmed specs:**
- Displays as circle everywhere. Upload square, min 320×320 px. Instagram compresses.
- JPG or PNG. Keep important art in center 70% (edges get cropped).

**Expert recommendation for GLOWAMOUR:**
- **Best:** Wordmark “GLOWAMOUR” or “GA” monogram on solid background (deep maroon / emerald / soft gold — premium skincare feel). High contrast, readable at 40px small size.
- **Do:** 1080×1080 PNG, centered, 150px padding all sides, test on dark + light mode.
- **Don’t:** Full product bottle photo (unreadable when small), busy lifestyle image, tiny tagline text, white-on-cream low contrast.
- **Consistency:** Use SAME logo on Instagram, WhatsApp DP, packaging sticker, parcel tape. Recognition = trust.

**How to check:** Upload → view profile on another phone → can you read it in comments + Stories circle? If not, simplify.

**Missing info:** If you don’t have a logo yet, use clean text on solid color temporarily (Canva free: 1080×1080 → bold font → export PNG). Don’t delay launch for perfect branding.

## 6. Contact Buttons + Business Info

**Confirmed:** Business accounts can add Email, Phone, WhatsApp, Location, Hours + action buttons.

**Recommended for GLOWAMOUR (priority order):**
1. **WhatsApp Button:** `Edit Profile > Contact Options > WhatsApp` — link your business WhatsApp number. This is your #1 sales channel in India. Label shows “WhatsApp”.
2. **Phone/Call (optional):** Only if you can answer 10am-8pm. Otherwise skip — missed calls hurt trust.
3. **Email:** `care@glowamour.in` or Gmail temporarily (e.g., `glowamourcare@gmail.com`). Use for order issues.
4. **Location:** `Ahmedabad, Gujarat, India` — helps Map search + local trust. Use area (e.g., “Ahmedabad”) not full home address for privacy.
5. **Hours:** e.g., `Mon–Sat, 10am–8pm IST` — sets reply expectations.

**Why:** Indians buy via chat. Every extra tap loses buyers. WhatsApp button + DM keyword + link = 3 easy paths.

## 7. Links — Website / Store / Ordering

**Confirmed (2024-2026):** You can add up to 5 links + a Facebook link in `Edit Profile > Links`. First link gets most taps. You can title each link. No need for Linktree if you use native links (faster, free, trusted).

**Recommended link stack for GLOWAMOUR (no website needed to start):**

1. **Title:** `🛍️ Order on WhatsApp (Fastest)` → Link: `https://wa.me/91XXXXXXXXXX?text=Hi%20GLOWAMOUR!%20I%20want%20to%20order%20Night%20Cream%20(GLOW)` — replace number. Pre-filled text increases orders.
2. **Title:** `💰 Price, Sizes & COD Info` → Link: WhatsApp catalog link OR a free Google Doc / Notion page with price list, sizes, shipping, COD, return policy. (Until you have a website.)
3. **Title:** `✨ How to Use Night Cream` → Link: Link to your “How to Use” Reel OR Highlights cover? Actually links must be URLs — so link to a pinned post? Workaround: create a free page or just point to Highlights in bio text. If no page, use: `FAQs & Reviews` → Google Drive folder / Instagram Guide.
4. **Title:** `⭐ Customer Reviews` → Same page section or a Highlights deep-link workaround: use a simple Carrd/Linktree-free page later.
5. **Future:** `🧼 Kesar Soap Waitlist` → Google Form to collect interest.

**If you get a website/Meesho/Amazon later:** Keep WhatsApp as Link #1 (highest conversion for new brands), Shop as #2.

**Link hygiene:** Use short, clean URLs. Test every link monthly. Never link to a personal Facebook or empty page.

**Missing info needed:** WhatsApp number, price list, COD + shipping policy. Without these, links can’t convert.

## 8. Call-to-Action (CTA) Strategy

**Simple English:** CTA = telling visitor exactly what to do next. Confused visitor = no sale.

**Primary CTA (everywhere):** `DM “GLOW” or Tap WhatsApp to Order`
- Why “GLOW”? Easy to remember, easy to filter/search in DMs, works in Gujarati/Hindi/English.

**Secondary CTAs by place:**
- Bio → `👇 Tap to Shop`
- Reels caption last line → `DM “GLOW” for price + COD details` / `Comment “GLOW” and we’ll DM you`
- Stories → Poll + `Tap WhatsApp button to order`
- Highlights covers → `Shop 🛍️`
- Pinned posts → `Read caption for price + how to order`

**Rules:**
- ONE primary CTA per post/Reel. Don’t say “Follow, like, share, comment, DM, click link, tag 3 friends” at once.
- For selling posts: CTA = order. For educational posts: CTA = save/share/follow. Alternate.
- Reply to ALL “GLOW” comments/DMs within 2-4 hours in business hours (early-stage trust builder).

- **Business:** Insights, contact buttons, location/hours, shopping features, ads, WhatsApp button, auto-replies via Meta Business Suite. **← CHOOSE THIS for GLOWAMOUR.**
